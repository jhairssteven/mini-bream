# BlueBoat visualization meshes

Meshes from the [ArduPilot SITL BlueBoat Gazebo model](https://github.com/ArduPilot/SITL_Models/tree/master/Gazebo/models/blueboat)
(approximation of the Blue Robotics BlueBoat hull). Used by `urdf/blueboat.urdf` for RViz
`RobotModel` display.

Source commit: `master` branch, `Gazebo/models/blueboat/meshes/`.
